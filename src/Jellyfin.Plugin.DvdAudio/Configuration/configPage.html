Point this plugin at DVD-Audio .iso files or folder rips that contain AUDIO_TS. Music is published as FLAC. A hybrid disc that also has VIDEO_TS is linked into the movie library so Jellyfin's own DVD playback is used. CPPM-protected audio (DVDAUDIO.MKB) is listed and skipped. This plugin does not decrypt CSS or CPPM.

Choosing a library fills the path below. Albums are written to Artist/Album inside that folder.
Hybrid video zones are linked under a DVD-Audio folder in this library. An image that already lives here is not copied again.
Optional. One folder or .iso path per line. Semicolons also work. The music and movie roots are searched too.
Both modes produce real FLAC, so direct play and seeking work. Cache mode keeps the large files in the server data directory.
Existing album.nfo files are left alone. An existing movie link is not replaced.
